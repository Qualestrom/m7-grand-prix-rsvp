2. **Build**: Run `npm run build` (`tsc -b && vite build`) to verify 0 errors.

5. **Refine**: Automatically fix flaws and repeat the loop until the command is matched with high fidelity.
6. **Deploy**: Sync to `Documents/GitHub/m7-grand-prix-rsvp` and push to `origin/main`.
